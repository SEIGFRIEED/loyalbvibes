# loyaltyvibes

Sitio estatico para LOYALTYVIBESFOREVER listo para publicarse en GitHub Pages.

## Publicacion

1. Crear un repositorio en GitHub.
2. Subir la rama `main`.
3. En `Settings > Pages`, publicar desde la rama `main` y la carpeta raiz `/`.

## Aviso importante

La logica actual del frontend contiene credenciales de socio en `script.js`. Si publicas esta web tal como esta, cualquier persona podra verlas desde el codigo fuente del navegador.
